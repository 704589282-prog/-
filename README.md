# 包1：全数据要素基座平台（可交互前端原型）

本原型严格按“包1功能参数要求”组织页面，不按投标书章节组织。

## 页面信息架构（一级菜单）

1. 首页
2. 数据湖仓
3. AI中台
4. 数据中台
5. 业务中台
6. 数据汇聚接入
7. 数据治理与质控
8. 平台监控与运维

## 运行方式

```bash
python3 -m http.server 4173
```

浏览器打开：<http://localhost:4173>

## 页面能力

- 每个页面都提供：筛选区、统计卡片、图表、表格、状态标签、详情抽屉。
- 覆盖参数要求中的：数据湖仓、服务中台（AI/数据/业务）、数据汇聚接入、数据治理与质控、平台监控与运维。
